### 试听播放器（保留原生进度条 + 增强控制）

**布局结构：**
```
[⏪ 5s] [▶] [5s ⏩]  0:00 / 52:10    ← 控制按钮行
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   ← 原生进度条（保留）
┌──────────────────────────────────┐
│  前一句（灰色，半透明）            │   ← 字幕区域
│  【当前句（高亮，黄色背景）】      │
│  后一句（灰色，半透明）            │
└──────────────────────────────────┘
```

**功能说明：**
- `⏪ 5s` — 后退 5 秒
- `▶/⏸` — 播放/暂停切换
- `5s ⏩` — 前进 5 秒
- `0:00 / 52:10` — 当前时间 / 总时长
- 原生进度条保留，可拖动跳转

**字幕显示：**
- 前一句：灰色半透明显示
- 当前句：高亮（黄色背景 + 加粗）
- 后一句：灰色半透明显示
- 只在字幕索引变化时更新 DOM（性能优化）

**CORS 解决方案：**
- 字幕数据在构建时嵌入 HTML（`ep.cues` 字段）
- 无需 fetch 请求，完全本地运行
