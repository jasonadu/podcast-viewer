## 提示词

你是一位精通 HTML/CSS/JavaScript 的前端工程师与中文文字编辑。我提供了四份经过 OCR 识别的 PDF 文字结果（下文分别称为「文件一～文件四」），请把它们整理成一部完整的 HTML 格式电子书。

### 一、书籍结构与文件拆分

1. 先阅读参考目录，确定本书分为「第一部分」和「第二部分」两大部分，以及各部分包含的章节标题与顺序。
2. 文件拆分规则：
   - **第一部分**：每个章节生成一个独立的 HTML 文件，文件名形如 `part1-ch01.html`、`part1-ch02.html`……按目录顺序编号。
   - **第二部分**：每十条（按目录中的条目/小节计）合并为一个 HTML 文件，文件名形如 `part2-01-10.html`、`part2-11-20.html`……最后不足十条的单独成文件。
3. 生成一个总目录文件 `index.html`，列出全部章节与条目，每个条目都是可跳转的链接，指向对应 HTML 文件（需要时带锚点）。
4. 每个章节/合并文件中，正文只放该文件对应的内容，并在开头给出本章标题。第一部分文件内如需分节，用 `<h2>`/`<h3>` 并加 `id` 锚点。

### 二、OCR 纠错

1. 纠正 OCR 识别错误：错别字、形近字误识、漏字、多字、断行错乱、标点误用、全角/半角混用、数字与英文误识等。
2. 合并被错误断开的段落，删除页眉页脚、页码、扫描水印等噪声文字（如确属正文内容则保留）。
3. 保持原文语义与措辞，不做改写、增删内容；无法确定的字词保留原样并用 `<!-- 待核 -->` 注释标记。
4. 统一标点与引号风格，中文正文使用中文标点。

### 三、页面布局（所有 HTML 文件共用同一套样式与脚本）

**整体布局**
- 左右两栏：左侧固定目录 `nav#toc`（宽 300px），右侧主内容 `main`（`margin-left:300px`，最大宽 900px）。
- 目录 `position:fixed`，随页面滚动保持可见；右上角 ☰ 按钮可折叠/展开。
- 窄屏（≤900px）：目录默认隐藏为抽屉，点 ☰ 滑出，主内容占满全屏；窄屏点击目录链接后自动收起抽屉。
- 页面背景 `#faf6f1`，正文字号 18px。

**交互与状态**
- 目录折叠：`transform:translateX(-300px)` 过渡 0.25s；宽屏切 `hidden`，窄屏切 `show`。

**目录内容**
- `nav#toc` 内为本书完整目录（与 `index.html` 一致），当前文件对应的条目高亮显示。
- 目录顶部放「返回总目录」链接指向 `index.html`。
- 每个章节文件左侧目录同样可折叠，且包含全书目录以便跨章跳转。

**其他要求**
- 单文件自包含：CSS 写在 `<style>` 中，JS 写在 `<script>` 中，不依赖外部库与网络资源。
- 使用语义化标签（`<nav>`、`<main>`、`<article>`、`<h1>`～`<h3>`、`<p>` 等），编码 `UTF-8`，含 `<meta name="viewport">`。
- 保证宽屏与窄屏下均可用，折叠状态用 class 切换实现（如 `hidden` / `show`），不要用内联样式硬编码。
- 代码整洁、有缩进与必要注释。

### 四、输出方式

1. 先输出「整理说明」：书籍结构概览、文件清单（文件名 → 对应章节/条目）、主要纠错类型举例。
2. 再按顺序输出每个 HTML 文件的完整代码，每个文件用代码块包裹并标注文件名。
3. 最后输出 `index.html` 的完整代码。
